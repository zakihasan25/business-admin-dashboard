# Business Admin Dashboard — project summary

An independently built operations demo with a delivery-risk and recovery planner as its signature workflow.

Instead of only listing overdue work, it estimates whether current staffing can cover remaining project effort. Visitors can change a deadline, share an employee across projects, or transfer an assignment. The preview explains which projects gain capacity and which lose it before any records change.

A manager records a rationale, reviews the effects, and applies the plan. Browser-local decision history preserves before/after records; undo refuses to overwrite newer project edits.

The surrounding workspace includes employee and project management, sample financial analytics, notifications, role previews, responsive layouts, and light/dark themes. All data is fictional. This is independent portfolio work, not a client engagement, production prediction system, or real authentication service.
