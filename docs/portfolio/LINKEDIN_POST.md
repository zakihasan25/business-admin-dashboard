A project can look healthy after you move someone onto it—but what happens to the project they leave?

I built a delivery-risk and recovery planner to explore that tradeoff in an independent portfolio demo.

It calculates remaining effort against available weekday capacity, with each person's time shared across overlapping assignments. You can preview a deadline change or staffing transfer and see which projects gain capacity and which lose it before applying anything.

The workflow includes an explanation of each estimate, a recorded decision rationale, browser-local history, and an undo action that protects newer edits.

The surrounding dashboard includes employee management, projects, reporting, responsive layouts, and light/dark themes. Built with Next.js, React, TypeScript, and tested calculation and browser workflows.

This is a fictional frontend demonstration, not client work or a production prediction system. All calculations use visible assumptions; no AI service or backend is connected.
