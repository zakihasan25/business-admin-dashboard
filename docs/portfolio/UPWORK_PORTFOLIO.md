# Upwork portfolio copy

**Title:** Delivery Risk & Recovery Planner — Interactive Business Dashboard

**Role:** Frontend engineer, product designer, and workflow architect

**Short description:** Beyond tracking projects, this dashboard helps managers compare recovery decisions. An explainable capacity model shows how staffing transfers and deadline changes affect the selected project and competing assignments before a plan is applied. Recorded reasoning, browser-local decision history, and undo that protects newer edits complete the workflow. Independently built with fictional data; no backend or real authentication.

**Skills:** React, Next.js, TypeScript, SaaS product design, scenario modeling, data visualization, accessible forms, local persistence, automated testing, static deployment.

**Recommended media:** Lead with delivery-recovery-planner.png. Show the selected project's capacity gap closing beside another project's lost capacity. Follow with overview, mobile planner, and a 45–60-second recording of preview → review → apply → undo.

**Honest positioning:** The model uses explicit effort and weekday-capacity assumptions. It is a planning estimate, not a validated forecasting model, employee-performance assessment, or AI integration. This is independent portfolio work, not client work. Add a live URL only after verifying your own deployment.
